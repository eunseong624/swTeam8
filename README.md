# 단지메이트 MVP · 소프트웨어공학 8조

아파트 단지 전체가 함께 쓰는 AI 컴패니언 플랫폼 단지메이트의 시연용 MVP예요. 시나리오 5개(단지 내 로봇 활용, 층간소음, 층간흡연, 이중주차, 헬스케어 패밀리)를 한 페이지에서 눌러 볼 수 있어요.

## 바로 열기

- 링크: https://eunseong624.github.io/swTeam8/
- 크롬에서 열고, 카메라와 마이크 권한을 물어보면 허용해요. 그래야 얼굴 인식과 음성 인식이 동작해요.

## 내 컴퓨터에서 열기 (VS Code)

카메라 얼굴 인식, 음성 인식, 블루투스 연결은 `localhost` 주소로 크롬에서 열어야 동작해요. `index.html`을 더블클릭해서 열면 카메라가 막혀요.

1. 저장소를 내려받고 VS Code에서 `파일 > 폴더 열기`로 폴더를 열어요. `lib`, `models` 폴더가 같이 있어야 해요.
2. 왼쪽 확장 프로그램 탭에서 **Live Server** (Ritwick Dey)를 설치해요.
3. `index.html`을 우클릭하고 **Open with Live Server**를 눌러요.
4. `http://127.0.0.1:5500` 주소가 열려요. 기본 브라우저가 크롬이 아니면 이 주소를 크롬에 붙여 넣어요.

## 맥에서 한 번만 확인

- 블루투스: 시스템 설정 > 개인정보 보호 및 보안 > 블루투스 > Google Chrome 켜기
- 카메라, 마이크: 시스템 설정 > 개인정보 보호 및 보안 > 카메라, 마이크 > Google Chrome 켜기
- 음성 인식은 크롬 기능이라 인터넷이 연결돼 있어야 해요.

## 시연 화면

처음 열면 발표용 시연 화면이 떠요. 위쪽 탭에서 시나리오를 고르고, 깜빡이는 버튼을 차례로 누르면 돼요.

- 층간소음, 층간흡연, 이중주차는 위쪽 **판별** 버튼(확정, 추정, 불확실)으로 경우를 바꿔 볼 수 있어요.
- 확정에서 끝까지 누르면 주민 정식 신고, 관리사무소 권고, 외부 기관 신고까지 이어져요. 불확실이면 관리사무소가 특정 세대를 지목하지 않고 라인 전체에 공동 안내를 보낼 수 있어요.
- 패키지는 2종이에요. APT Care Cloud는 시나리오 2~4, Healthcare Family Cloud는 시나리오 5예요. 단지 내 로봇 → 2. 단지 운영에서 구독을 끄면 그 탭이 잠겨요.
- 처리 기록과 측정값은 오른쪽 위 **상세 화면**에서 볼 수 있어요. 각 기록에 실제 동작인지 예시인지 표시돼 있어요.

## 구현 범위

- 실제 동작: 상대 세대 판별 3단계, 소음 기준 비교, 반복 횟수와 정식 신고, 순화와 익명 전달, 감정 점수, 얼굴 등록·확인과 표정 인식, 약 복용 단계 알림, 가족 일정 정렬, 패키지 구독
- 예시(정해 둔 값): 센서 측정값, 날씨와 병원 예약 같은 외부 연동(MCP), 가족 목소리 위로, 사진 고르기, 고향 기억
- LLM은 붙이지 않았어요. 의도 찾기와 문장 순화는 키워드 규칙으로 대신했어요.

## 쓰인 기술

- 얼굴 검출: TinyFaceDetector (Tiny YOLO v2 기반), 얼굴 특징값 128개 비교, 표정 인식 (`lib/face-api.js`, MIT 라이선스)
- 음성 인식: 크롬 Web Speech API (`ko-KR`)
- 기기 연결: 크롬 Web Bluetooth API
- 얼굴 사진과 영상은 브라우저 밖으로 나가지 않아요. 특징값만 화면 안 메모리에 저장되고 새로고침하면 지워져요.
